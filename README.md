# fitness-lp-demo — グループフィットネススタジオのLPデモ

グループフィットネススタジオを想定した、1ページ完結・レスポンシブ対応の
ランディングページのデモ。静的な HTML / CSS だけでどこまで作れるかを示すサンプル。

- 実体は `index.html` **1ファイルだけ**（HTML・CSS・JavaScript を全部その中に書いている）
- 画像ファイルは **0枚**。写真の代わりは全部 SVG（コードで描いた図形）
- 掲載しているスタジオ名・写真・文章・料金・住所・電話番号は**すべて架空**
- 店舗LPの一般的な構成（1ページ完結・メニュー6つ）で作成

## 見る

```bash
cd fitness-lp-demo
python3 -m http.server 8899
# ブラウザで http://127.0.0.1:8899/index.html を開く
```

ファイルをダブルクリックで開いても表示される（サーバー不要）。

## 中身

| 場所 | 何が書いてあるか |
|---|---|
| `index.html` 12行目あたり `:root{...}` | **色・余白・最大幅・書体**。ここだけ変えれば全体の印象が変わる |
| `.section` 〜 `.btn` | 全ページ共通の部品（見出し・ボタン・写真枠） |
| `@media (max-width:1024px)` | タブレット表示。ここでメニューがハンバーガーに変わる |
| `@media (max-width:640px)` | スマホ表示 |
| `<body>` 以下 | 本文。`<!-- ===== 1. ファーストビュー ===== -->` のようにセクションごとにコメントを入れてある |
| 一番下の `<script>` | 動いているのは4つだけ（ヘッダー背景 / メニュー開閉 / 現在地の下線 / ふわっと表示とFAQ開閉） |

自分で直すときの具体的な手順は `docs/self_edit_guide.md`。

## 確認済み（2026-09-11・Chrome 実機表示）

- PC 1440px / タブレット 820px / スマホ 390px で表示確認。横スクロール発生なし
- スマホのハンバーガーメニュー開閉が動作すること（実際にクリックして確認）
- コンソールのエラー・警告 0件
- ページ容量 約43KB（画像なし・外部読み込みは Google Fonts のみ）

## 直した不具合（記録）

1. アイコンと番号が同じ行に並んだ → `svg` は既定が inline なので `display:block` を指定
2. 料金のチェック印が「∨」に見えた → 8×8px の正方形を回していたため。9×5px に変更
3. 体験の流れに `1.` `2.` の数字が出た → `ol` にも `list-style:none` を適用
4. **スマホでメニューが開かなかった** → ヘッダーの `backdrop-filter` が `position:fixed` の基準を奪っていた。タブレット以下では `backdrop-filter` を外す
