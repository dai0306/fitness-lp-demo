# 自分で直す手順

修正のご依頼を受けたとき、**どこを開いて何を書き換えるか**をまとめたもの。
直す場所はほぼ `index.html` の中だけ。この1ファイルで完結している。

作業のかたち（毎回これ）:

1. `index.html` をエディタで開く
2. 下の逆引き表で「直す場所」を探す
3. 書き換えて保存する
4. ブラウザで開いて、**390px / 820px / 1440px** の3つの幅で見る（→ 最後の「確認」の章）
5. 元に戻したくなったら `git checkout index.html`（保存前なら Ctrl+Z）

## まず読む：言われた言葉から場所を引く

| 言われそうなこと | 直す場所 | 章 |
|---|---|---|
| 「緑をもう少し濃く／別の色にして」 | `:root` の `--green` と `--green-deep` | 1 |
| 「全体をもっと明るく／落ち着いた感じに」 | `:root` の `--cream` `--mist` `--sage` | 1 |
| 「ボタンの色を変えて」 | `:root` の `--green`（ボタンは全部これを見ている） | 1 |
| 「もう少し詰めて／間隔を空けて」 | `.section{ padding: 88px 0 }` の数字 | 2 |
| 「余白が広すぎる（スマホで）」 | `@media (max-width: 640px)` の中の `--pad` と `.section` | 2 |
| 「横幅がもっと広いほうがいい」 | `:root` の `--maxw: 1120px` | 2 |
| 「文字が小さい／大きい」 | 該当セクションの `font-size`。本文全体なら `body{ font-size }` | 2 |
| 「この文章を変えて」「料金を直して」 | `<body>` 以下。セクションごとにコメントが入っている | 3 |
| 「写真を入れて／差し替えて」 | `images/` に置いて `<img>` を1行足す | 4 |

| 「並び順を変えて」 | `<section>` のかたまりごと入れ替え＋メニューの順番も合わせる | 5 |
| 「電話番号／住所／営業時間を直して」 | ACCESS と CONTACT のセクション | 3 |
| 「Instagram のリンク先を変えて」 | `href="https://..."` を書き換え | 3 |
| 「地図を実際のものにして」 | Googleマップの埋め込みコードに差し替え | 6 |
| 「タブに出るアイコンを入れて」 | `<head>` に1行足す | 7 |
| 「スマホで見たら崩れている」 | まず幅を測る（→ 確認の章）。原因の当たりは最後の表 | 確認 |

**迷ったらブラウザの F12 → 左上の矢印アイコン → 直したい部分をクリック**。
右側に、その部分に効いている CSS とファイルの行番号が出る。そこを直せばよい。

## 1. 色を変えたい

`index.html` の上のほう、`:root{` の中だけを直す。ページ全体に反映される。

```css
--cream:      #FCFAF7;   /* 一番明るい背景（ほぼ白） */
--mist:       #F5F0E7;   /* 薄いベージュの背景（1セクションおきに使用） */
--sage:       #DED3C2;   /* 中間のベージュ（飾り線・図版） */
--green:      #6F8B73;   /* 差し色（ボタン・アイコン） */
--green-deep: #3E5347;   /* 濃い差し色（ファーストビュー・お問い合わせの背景） */
--gold:       #C4AE8E;   /* もうひとつの差し色。番号 01/02/03 に使用 */
```

- **差し色を変える**ときは `--green` と `--green-deep` の2つを入れ替える
  （`--green-deep` は `--green` より濃い同系色にする）
- **背景**（`--cream` / `--mist` / `--sage`）は白〜ベージュのままにしておくほうが、全体の印象が崩れない
- 「濃く」= 16進数の数字を小さく、「薄く」= 大きくする。
  迷ったら [oklch.com](https://oklch.com/) などで色を選んで貼り替える

色を変えたら、**文字が読めるか**を必ず見る（薄い背景に薄い文字になっていないか）。

## 2. 余白・文字の大きさを変えたい

| 対象 | 直す場所 |
|---|---|
| セクションの上下の余白 | `.section{ padding: 88px 0; }` の 88px |
| 左右の余白 | `:root` の `--pad: 24px` |
| コンテンツの最大幅 | `:root` の `--maxw: 1120px` |
| スマホの余白 | `@media (max-width: 640px)` の中の `--pad:20px` / `.section{ padding:60px 0 }` |
| 本文の文字サイズ | `body{ font-size: 15px }`（スマホは `@media` の中の `body{ font-size:14px }`） |
| 見出しの文字サイズ | 英字の小見出し `.head__en` / 日本語の見出し `.head__jp` / 説明文 `.head__lead` |
| ファーストビューの大見出し | `.hero__title` |

`clamp(16px, 2vw, 20px)` のような書き方は「最小 / 画面幅に応じて / 最大」の意味。
真ん中の値を変えると、画面幅による変化のしかたが変わる。

## 3. 文章・料金・連絡先を差し替えたい

`<body>` から下。セクションごとに `<!-- ===== 3. Instagram ===== -->` のような
コメントが入っているので、直したい場所の日本語を書き換えるだけ。

**注意**: `<` と `>` で囲まれた部分（タグ）は消さない。日本語だけ入れ替える。

```html
<!-- OK -->
<h3 class="about__title">ここを書き換える</h3>

<!-- NG（タグを壊している） -->
<h3 class="about__title>ここを書き換える</h3>
```

## 4. 写真を入れたい・差し替えたい

写真が入る枠には目印（`data-photo="..."`）が付けてある。全部で8か所。

| 目印 | 場所 | おすすめの形 |
|---|---|---|
| `hero` | ファーストビューの背景 | 横長（3:2 くらい）・明るめの写真 |
| `about` | スタジオ紹介 | 縦長（4:5）。スマホでは横長に切り取られる |
| `ig1`〜`ig6` | Instagram の6枚 | 正方形 |

### 手順（手作業）

1. 写真を [Squoosh](https://squoosh.app/) にドラッグして小さくする
   - 横幅の目安: `hero` は 1800px、`about` は 1200px、`ig1`〜`ig6` は 700px
   - 容量の目安: **1枚 250KB 以下**
2. `index.html` と同じ場所に `images/` フォルダを作り、その中に入れる
3. `index.html` で目印を検索する（例: `data-photo="about"`）
4. **その行のすぐ下に、`<img>` を1行足すだけ**

```html
<div class="ph about__ph reveal" data-photo="about" data-photo-alt="スタジオの内観">
  <img src="images/studio.jpg" alt="スタジオの内観">        ← この1行を足す
  <svg ...>...</svg>                                        ← 消さなくてよい
  <span class="ph__note">お写真が入ります</span>            ← 消さなくてよい
</div>
```

仮置きの図形と「お写真が入ります」の文字は、**写真が入ると自動で隠れる**（CSS がそうしている）。
だから消す必要はなく、`<img>` の行を消せばいつでも元の見た目に戻せる。

`alt="..."` には写真の内容を短く書く（目の不自由な方の読み上げと、検索エンジン向け）。

### ファーストビュー（hero）に写真を入れるとき

`<section class="hero">` を `<section class="hero hero--has-photo">` に変える。
これを付けないと、飾り用の薄い表示のままで写真がぼんやりする。

写真が暗くて文字が読みにくいときは `.hero--has-photo .hero__veil` の
`rgba(255,255,255,.86)` の数字を大きくする（1に近いほど白くかぶる）。

### 写真の位置がおかしいとき

枠に合わせて自動で切り取られる。切り取る位置を変えたいときは `<img>` にこう足す:

```html
<img src="images/studio.jpg" alt="スタジオの内観" style="object-position: top;">
```

`top` / `center` / `bottom` / `20% 40%`（左から20%・上から40%）などが使える。

### 写真がたくさんあるとき（おまけ・任意）

`tools/apply_images.py` を使うと、縮小・圧縮・`<img>` の差し込みをまとめてやる。
**使わなくても上の手作業だけで全部できる**ので、面倒なときだけ。

```bash
python3 tools/apply_images.py --list    # 枠の名前と、今どこに何が入っているかを見る
python3 tools/apply_images.py           # images/ の写真をまとめて反映する
python3 tools/apply_images.py --revert  # 1つ前の状態に戻す
```

写真は `images/` に **枠の名前.jpg**（`hero.jpg` `about.jpg` `ig1.jpg` …）で置く。
`images/` から写真を消してもう一度実行すると、元の枠の見た目に戻る。

## 5. メニュー・セクションを増やす／減らす

2か所を同じだけ直す。**片方だけ直すとリンクが切れる**。

1. ヘッダーの `<nav class="nav">` の中の `<li>`
2. フッターの `<nav class="footer__nav">` の中の `<a>`

セクション自体を増やすときは `<section class="section" id="新しい名前">` を足し、
メニューの `href="#新しい名前"` と一致させる。

並び順を変えるときは、`<section>` の開始タグから終了タグまでを丸ごと移動する。
メニューの並びも同じ順にそろえる。

## 6. 地図を実際のものにする

1. Googleマップでその住所を出す → 共有 → 「地図を埋め込む」→ HTML をコピー
2. `data-photo` が付いていないほうの枠、`<div class="ph access__map ...>` の中身を
   コピーした `<iframe ...>` に置き換える
3. `<iframe>` に `style="width:100%;height:100%;border:0;"` を足す

## 7. タブに出るアイコン（ファビコン）を入れる

正方形の画像を `images/favicon.png` として置き、`<head>` の中に1行足す。

```html
<link rel="icon" href="images/favicon.png">
```

## 直したあとの確認（毎回やる）

1. ブラウザで開いて **F12 → 左上のスマホアイコン**（Toggle device toolbar）
2. 幅を **390px / 820px / 1440px** に切り替えて、それぞれ見る
3. **横スクロールバーが出ていないこと**。出ていたら Console に次を貼って調べる:
   ```js
   document.documentElement.scrollWidth, window.innerWidth
   ```
   この2つの数字が同じならOK。前のほうが大きいと、はみ出している要素がある
4. メニューの6項目を全部クリックして、正しい場所へ飛ぶか
5. スマホ幅でハンバーガーメニューを開閉してみる
6. **F12 の Console タブに赤いエラーが出ていないこと**
   （`favicon.ico` の404だけは、アイコン未設定のとき必ず出るもので無害）
7. 写真を入れたなら、その写真が実際に表示されているか（ファイル名の打ち間違いが一番多い）

## 困ったときの当たり表

| 症状 | 疑う場所 |
|---|---|
| 写真が出ない（枠のまま） | ファイル名の打ち間違い。大文字小文字も区別される（`Photo.JPG` ≠ `photo.jpg`） |
| 写真が伸びている・つぶれている | `<img>` が `[data-photo]` の枠の**外**に出ていないか |
| ページが重い・表示が遅い | 写真の容量。1枚250KB以下、合計2MB以下を目安に |
| 横スクロールが出る | 幅を `px` で固定した箇所。`max-width:100%` にする |
| スマホでメニューが開かない | ヘッダーに `backdrop-filter` / `transform` / `filter` が付いていないか（これが付くと中の `position:fixed` が画面基準でなくなる） |
| 文字が全部同じ書体になった | Google Fonts の `<link>` 行が消えていないか |
| 見出しが header に隠れる | `html{ scroll-padding-top: ... }` の値をヘッダーの高さに合わせる |
| アイコンや画像が横並びになる | その要素に `display:block` を付ける（`svg` と `img` は既定が inline） |
| 何をしても直らない | `git checkout index.html` で最後に保存した状態へ戻してやり直す |
