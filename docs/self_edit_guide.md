# 自分で直す手順

よくある修正依頼は次の5種類。すべて `index.html` の中だけで完結する。

## 1. 色を変えたい（「もう少し濃い緑に」など）

`index.html` の上の方、`:root{` の中だけを直す。ページ全体に反映される。

```css
--green:      #6F8B73;   /* ボタン・アイコンの緑 */
--green-deep: #3E5347;   /* 濃い緑（ファーストビュー・お問い合わせの背景） */
--sage:       #B9C9B8;   /* 薄い緑（飾り線・図版） */
--cream:      #FAF8F4;   /* 一番明るい背景 */
--mist:       #EFF2EC;   /* 薄い緑の背景（1セクションおきに使用） */
--gold:       #C4AE8E;   /* 差し色。番号 01/02/03 に使用 */
```

「濃く」= 数字（16進数）を小さく、「薄く」= 大きくする。迷ったら
[https://oklch.com/](https://oklch.com/) のようなカラーピッカーで選んで貼り替える。

## 2. 余白を変えたい（「もう少し詰めて」「間隔を空けて」）

| 対象 | 直す場所 |
|---|---|
| セクションの上下の余白 | `.section{ padding: 88px 0; }` の 88px |
| 左右の余白 | `:root` の `--pad: 24px` |
| コンテンツの最大幅 | `:root` の `--maxw: 1120px` |
| スマホの余白 | `@media (max-width: 640px)` の中の `--pad:20px` / `.section{ padding:60px 0 }` |

## 3. 文章・料金を差し替えたい

`<body>` から下。セクションごとに `<!-- ===== 3. Instagram ===== -->` のコメントが
入っているので、直したい場所の日本語を書き換えるだけ。

**注意**: `<` と `>` で囲まれた部分（タグ）は消さない。日本語だけ入れ替える。

## 4. 写真を入れたい

今は写真の代わりに SVG（コードで描いた図形）が入っている。差し替え方:

```html
<!-- 変更前 -->
<div class="ph about__ph reveal">
  <svg ...> ... </svg>
  <span class="ph__note">お写真が入ります</span>
</div>

<!-- 変更後 -->
<div class="about__ph reveal">
  <img src="images/studio.jpg" alt="スタジオの内観">
</div>
```

- `index.html` と同じ場所に `images/` フォルダを作って画像を置く
- `class` から `ph` を外す（`ph` は「写真枠の代わり」用の見た目なので）
- 画像は事前に圧縮する。目安は **1枚 200KB 以下**。
  [Squoosh](https://squoosh.app/) にドラッグして WebP か JPEG で書き出す

## 5. メニューの項目を増やす・減らす

2か所を同じだけ直す。**片方だけ直すとリンクが切れる**。

1. ヘッダーの `<nav class="nav">` の中の `<li>`
2. フッターの `<nav class="footer__nav">` の中の `<a>`

セクション自体を増やすときは `<section class="section" id="新しい名前">` を足し、
メニューの `href="#新しい名前"` と一致させる。

## 直したあとの確認（毎回やる）

1. ブラウザで開いて F12 → 左上のスマホアイコンで表示幅を切り替える
   （**390px / 820px / 1440px** の3つを見る）
2. **横スクロールバーが出ていないこと**を確認する（出たら幅の指定を疑う）
3. メニューの6項目を全部クリックして、正しい場所へ飛ぶか確認
4. スマホ幅でハンバーガーメニューを開閉してみる
5. F12 の Console タブに赤いエラーが出ていないこと

## 詰まったときに見る場所

| 症状 | 疑う場所 |
|---|---|
| 横スクロールが出る | 幅を `px` で固定した箇所。`max-width:100%` にする |
| スマホでメニューが開かない | ヘッダーに `backdrop-filter` / `transform` / `filter` が付いていないか（これが付くと中の `position:fixed` が画面基準でなくなる） |
| 文字が全部同じ書体になった | Google Fonts の `<link>` 行が消えていないか |
| 見出しが header に隠れる | `html{ scroll-padding-top: ... }` の値をヘッダーの高さに合わせる |
| アイコンや画像が横並びになる | その要素に `display:block` を付ける（`svg` と `img` は既定が inline） |
